⚠ v1에서 수정된 사항

시세 예측은 회귀(Regression)가 맞습니다. v1의 가격 P25/P50/P75 예측은 분류 문제가 아니므로 제거했습니다.
대신 같은 비즈니스 가치를 분류 문제로 reframe한 버전을 새로 넣었습니다 — "이 가격에 등록하면 시세 대비 저가/적정/고가인가?" 라는 3-class 분류로.

이 제안서가 다루는 문제 형태

분류(Classification) — 입력을 정해진 라벨 집합 중 하나로 매핑.
이진분류 (정상/스팸), 다중분류 (전자기기/의류/도서/...), 순서형 다중분류 (저가/적정/고가) 모두 포함.

학습 v1 — MultinomialNB (베이스라인)

import pandas as pd, pickle
from sklearn.preprocessing import LabelEncoder
from sklearn.model_selection import train_test_split
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.pipeline import Pipeline

df = pd.read_csv('./datasets/products.csv').dropna().drop_duplicates(ignore_index=True)
enc = LabelEncoder(); df['target'] = enc.fit_transform(df.category)

X_train, X_test, y_train, y_test = train_test_split(
    df.title + ' ' + df.description, df.target,
    stratify=df.target, test_size=0.3, random_state=124)

pipe = Pipeline([('cv', CountVectorizer()), ('nb', MultinomialNB())])
pipe.fit(X_train, y_train)
print(pipe.score(X_test, y_test))
pickle.dump(pipe, open('category_model_v1.pkl', 'wb'))
pickle.dump(enc,  open('category_encoder.pkl', 'wb'))

FastAPI 서빙

from fastapi import FastAPI
from pydantic import BaseModel
import pickle

model = pickle.load(open('category_model.pkl', 'rb'))
enc   = pickle.load(open('category_encoder.pkl', 'rb'))
app = FastAPI()

class Req(BaseModel):
    title: str
    description: str

@app.post('/predict/category')
def predict(req: Req):
    text  = req.title + ' ' + req.description
    proba = model.predict_proba([text])[0]
    top3  = proba.argsort()[::-1][:3]
    return [{"name": enc.classes_[i], "confidence": float(proba[i])} for i in top3]

라벨 정의 (학습 시)

  • 최근 N일 같은 카테고리 체결가 분포에서:
  • 가격 ≤ P25 → cheap
  • P25 < 가격 ≤ P75 → fair
  • 가격 > P75 → expensive

입력 feature

  • category_id, condition(상/중/하), region_code
  • brand_keyword (CountVectorizer로 텍스트 처리)
  • price_input (정규화된 수치)

학습 v1 — DecisionTree

from sklearn.tree import DecisionTreeClassifier
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import OneHotEncoder, StandardScaler

pre = ColumnTransformer([
    ('cat', OneHotEncoder(handle_unknown='ignore'),
        ['category_id', 'condition', 'region_code']),
    ('num', StandardScaler(), ['price_input']),
])
pipe = Pipeline([('pre', pre),
                 ('dt', DecisionTreeClassifier(max_depth=10, random_state=124))])
pipe.fit(X_train, y_train)  # y ∈ {cheap, fair, expensive}

왜 분류로 풀어도 되나

  • 사용자에게 보여줄 정보는 "이 가격이 적정한가" 한 줄.
  • 정확한 시세 원 단위 숫자가 꼭 필요하지는 않음.
  • 회귀(원) → 분류(저/중/고)로 reframe하면 학습한 기법으로 충분.

tabular + 텍스트 둘 다 가장 강한 SOTA 베이스라인. scale_pos_weight·is_unbalance로 불균형 처리.

Pipeline + train_test_split + cross_val_score

  • 모든 모델 학습/검증 워크플로우 공통
  • stratify=y로 클래스 비율 유지
  • cv=5, scoring='f1_macro'로 다중분류 평가
  • 이진분류는 roc_auc·average_precision도 같이 확인

LabelEncoder + pickle (+ joblib)

  • 모든 분류 모델: model.pkl + encoder.pkl 한 쌍
  • 큰 부스팅 모델은 joblib.dump(compress=3) 추천
  • FastAPI 시작 시 1회 로드 → 재사용
  • 버전 관리: {name}_v{n}.pkl
